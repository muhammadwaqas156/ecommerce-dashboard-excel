# 📊 E-Commerce Performance Dashboard (Excel)

## 📌 Overview

This project presents an interactive & dynamic e-commerce dashboard built using Excel. It analyzes customer behavior, sales performance, product insights, and logistics efficiency.

---

## 🔧 Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Data Model (DAX Measures)

---

## 📈 Key Features

* 💰 Total Revenue, Orders, and AOV tracking
* 👥 Customer segmentation (High, Medium, Low value)
* 📦 Product performance analysis
* 📊 Monthly sales trend visualization
* 🚚 Logistics performance (Delivery vs Delayed)
* 🔄 Return rate analysis


---

## 🧠 Insights

* 89% of orders were successfully delivered
* High-value customers contributed the majority of revenue
* Electronics category dominated product sales
* Returns were primarily due to defective and late deliveries

---

## 📁 Dataset

The dataset includes:

* Customers
* Orders
* Products
* Payments
* Shipments
* Returns
